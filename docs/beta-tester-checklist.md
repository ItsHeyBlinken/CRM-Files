**Rules:** Fake data only · ~45–60 min · try the client steps on your phone.

## Part A — Vendor (~30–40 min)

- [ ] Register as vendor at the site
- [ ] Finish onboarding / payment settings if prompted (placeholder Venmo/Zelle/etc. is fine — no real money)
- [ ] **Settings:** business name, tagline, colors; optional logo
- [ ] Optional: **Inquiries** → add Alex & Jordan Miller
- [ ] **Quotes** → create quote with 2+ line items + event date
- [ ] Attach a short PDF contract (optional but recommended)
- [ ] Copy the **public quote link**
- [ ] Open quote link in **incognito** or on phone → Accept → Sign if contract attached
- [ ] As vendor: confirm **project + deposit invoice + portal invite** exist (auto after accept/sign; otherwise use **Convert to project**)
- [ ] Copy **client invite link** from the project
- [ ] Check Home / notification bell for activity

## Part B — Client portal (~15–20 min, phone preferred)

- [ ] Open invite link → create password → enter portal
- [ ] In ~3 seconds: see date, status, and next step?
- [ ] Branding looks like the vendor (name / logo / colors)?
- [ ] **Documents:** view / sign contract
- [ ] **Payments:** see deposit; try options or “I’ve sent payment” (fake only)
- [ ] As vendor again: mark invoice paid if needed

## Known limits (not bugs)

- No client gallery / file downloads yet  
- Links are often copy/paste (email may not auto-send)  
- Stripe card link is optional for this test
